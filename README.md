# 🤖 Text-to-SQL 智能数据库查询助手

一个基于 **DeepSeek + Streamlit + SQLite** 开发的自然语言数据库查询应用。

用户上传 CSV 或 Excel 文件后，系统会自动读取数据并构建 SQLite 数据库。通过接入 DeepSeek 大语言模型，用户可以直接使用自然语言提出数据查询需求，系统自动生成并执行 SQL 语句，并以数据表、可视化图表和文字总结的形式展示查询结果。同时，系统支持多轮对话追问和历史记录导出，让数据查询与分析更加简单、高效。

## ✨ 核心功能

- **多类型文件上传**：支持 CSV、Excel 等表格文件。
- **自动构建数据库**：将上传的数据加载到 SQLite 数据库中，方便后续查询。
- **数据概览展示**：展示已加载的数据表及相关信息。
- **AI 智能推荐问题**：根据数据内容推荐可供选择的查询问题。
- **自然语言转 SQL**：利用 DeepSeek 将自然语言问题转换为 SQL 查询语句。
- **SQL 查询执行**：执行生成的查询语句，并以表格形式展示查询结果。
- **智能数据可视化**：根据查询结果生成相应的图表。
- **自然语言结果总结**：对查询结果进行解释和归纳，帮助用户理解数据。
- **多轮对话追问**：支持基于上下文继续提问和分析。
- **历史记录导出**：支持导出历史对话，方便保存和整理。
- **SQL 安全检查**：对生成的 SQL 进行检查，并通过只读执行限制降低误操作风险。

## 🚀 运行项目

### 1. 克隆项目

将下面的仓库地址替换为你自己的 GitHub 仓库地址。

```bash
git clone https://github.com/YOUR_USERNAME/text-to-sql.git
cd text-to-sql
```

### 2. 安装依赖

建议使用 Python 虚拟环境。进入项目目录后，执行：

```bash
pip install -r requirements.txt
```

### 3. 配置 DeepSeek API Key

在项目根目录下创建 `.env` 文件，并配置自己的 DeepSeek API Key：

```env
DEEPSEEK_API_KEY=your_deepseek_api_key
```

将 `your_deepseek_api_key` 替换为你自己的 API Key。

**注意：请勿将真实 API Key 上传到 GitHub。** 建议在 `.gitignore` 文件中添加 `.env`，避免将密钥提交到公开仓库。

### 4. 启动应用

在项目根目录下执行：

```bash
streamlit run app.py
```

启动成功后，根据终端提示在浏览器中打开应用地址，即可开始使用。

## 💡 项目亮点

本项目将大语言模型与关系型数据库查询相结合，把传统的 SQL 编写过程转化为自然语言交互过程。用户可以通过简单的提问完成数据查询、结果查看、图表分析和多轮追问，降低了数据库查询的使用门槛，也提高了表格数据探索与分析的效率。
